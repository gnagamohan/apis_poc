nginx entry point

pgAdmin /pgadmin/ - PostgreSQL (pgvector) admin UI Get a token /login - log in with email and password, then copy the JWT
Login (auth-service) POST /auth/login - {"email", "password"} returns a JWT valid for 10 minutes; also /auth/signup, /auth/password-reset/request, /auth/password-reset/confirm, /auth/password/change (JWT)
Mailpit /mailpit/ - dev mail catcher: password-reset and password-changed emails land here
To-do API (via Spring Cloud Gateway, JWT required) /api/todos - GET, POST, PUT /{id}, DELETE /{id} with Authorization: Bearer <token>
To-do MCP server (Play, via gateway, JWT required) http://localhost/mcp - Streamable HTTP; tools: list_todos, get_todo, create_todo, update_todo, delete_todo
